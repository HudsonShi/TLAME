# TLAME
## 1. 评测集介绍
### 1.1 评测集概述
TLAME（Transportation Large-Language Model Assessment and Metrics Evaluation）是由阿拉巴马大学土木建筑与环境学院设计的面向交通运输领域大模型评测体系，旨在全面评估大模型在交通运输领域的专业能力和实践表现。
TLAME评测体系包含两大核心评测集：
TLAME-Cer（Transportation Certification）：覆盖 FE、PE-Transportaion、PTOE、PTP等多种权威交通运输资格认证，所有题目经过人工审核，确保准确性和代表性；
TLAME-Sce（Transportation Scenario）：包含多个交通运输，交通工程，交通规划等业务场景应用任务的评测集合。
